## 1. 今回の目的

G2で仮決定した「戻り再構成型」を、本番素材を使わずに仮図形へ接続する。

確認する中心仮説は次の一文である。

> 成功ショットで戻り道が変わり、変化した戻り道が次の狙いとフリッパー操作を変える。

この記録は、仕様を決めたことと、中心体験が面白いことを分けて扱う。初見理解、3〜5ゲーム後の上達、端末上の操作感は、G3 / GAの試遊でまだ確認していない。

## 2. 実装した範囲

### 仮図形テーブル

- 左右の安全ショット: `L0` / `R0`
- 左右の中核ショット: `L1` / `R1`
- 左右の危険ショット: `L2` / `R2`
- 中央接続: `C0`
- 中枢入口: `C1`
- 各ショットに入口、確認点、出口の3センサー
- 戻りルートを表す8個の物理ゲート

### 進行

- 開始時は`L0`または`R0`を選べる
- `L0`成功後は`R1`、`R0`成功後は`L1`へ切り替える
- 中核から危険、中央接続、中枢入口へ進む
- 成功したショットごとに、次の目標、戻りルート、今回の得点、連続成功をメモリ内だけで更新する
- `C1`成功時は仮のクライマックス状態へ入る

### 物理との接続

- 成功イベントの後、次の固定ステップで旧ゲートを閉じ、新しい戻りゲートを開く
- 表示状態だけを変えず、Planckの衝突フィルターも更新する
- リセット時に進行、得点、ゲート、ショット途中状態を初期化する
