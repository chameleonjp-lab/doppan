## 1. 目的

技術的に作れるかだけでなく、現在遊べる作品の中でDOPPANをどう説明するかを決める。

目的は既存作品を避けることではない。似た機能がある場合でも、DOPPANでどの判断、技能、感情の流れが異なるかを説明できる状態にする。

## 2. 比較対象

現在遊べる作品から8〜12件を選ぶ。

最低限含める。

- スマホ向けピンボール
- ブラウザ向けピンボール
- 技能型のスコアアタック
- ピンボールと別ジャンルを組み合わせた作品
- 見た目と演出を強く打ち出した作品
- 初心者向け支援がある作品

OSS調査だけで完了としない。完成済みの商用作品、個人作品、無料作品も確認する。

## 3. 比較項目

| 項目 | 確認内容 |
|---|---|
| 対応端末 | スマホ、PC、ブラウザ |
| 操作 | 左右入力、発射、台揺らし |
| 1ゲーム時間 | 短時間か長時間か |
| 球の保持 | 狙い直せるか |
| ショット技能 | 意図した経路を狙えるか |
| 盤面進行 | 球間で何が残るか |
| クライマックス | 最終達成やマルチボール |
| 初心者支援 | 案内、練習、ボールセーブ |
| 得点戦略 | 偶発接触か狙いか |
| 独自要素 | 世界観とルールの結び付き |
| 終了設計 | 一回の区切り |
| 演出 | 音、光、振動の段階 |
| 収益化 | 広告、課金、買い切り |
| DOPPANとの差 | 一文で記載 |

## 4. 調査方法

各作品について次を記録する。

- 公式説明
- 公開日または更新状況
- 実際のプレイ確認の有無
- 参考にする点
- 避ける点
- DOPPANと重なる点
- DOPPANが変える必要がある点

調査時点の日付を必ず記録する。現在の情報はWeb検索で確認し、内部知識だけで埋めない。

## 5. 独自性の判定

DOPPANの一文が、比較対象の名称へ置き換えても成立する場合は不合格。

合格には、次のいずれかが必要。

- 固有の技能
- 固有の盤面進行
- 固有のクライマックス
- 世界観とショットが一体になったルール
- スマホ操作だから成立する判断

「派手」「爽快」「覚醒」「技能型」だけでは固有価値としない。

## 6. 名称確認

「DOPPAN」は、正式公開名として未確定とする。リポジトリ名はそのまま使ってよい。

確認する場所:

- 一般Web検索
- App Store
- Google Play
- Steam
- itch.io
- GitHub
- SNSの主要アカウント名
- ドメイン
- 日本の商標検索
- 読み方が近い名称
- 海外での意味や不適切な連想

確認内容:

- 完全同名
- 類似したゲーム名
- 同じ分野の商標
- 検索時に著名名称へ埋もれないか
- 読み方を一つに定められるか
- URLやSNS名を確保できるか

この確認は法的保証ではない。重大な懸念がある場合は、専門家確認または名称変更を選ぶ。

## 8. G0.5通過条件

- 比較対象8件以上
- DOPPANとの差を一文で説明
- 一文が実際の正式版1.0範囲で証明可能
- 正式名称の扱いを決定
- 重大な名称衝突が未解決でない
- 参照した作品の画像、音、盤面を模倣しない方針を確認

## 9. 2026-08-11の実施結果

10作品を比較し、スマホ、ブラウザ、技能型、融合型、短時間作品を含めた。調査結果の詳細は[G0.5市場・名称調査記録](./G0_5_MARKET_NAME_RESEARCH_2026-08-11.md)に残す。

現在の仮説は、次の一文である。

> 球を打ち返すたびに戻り道をつなぎ直し、次に狙う場所を変えながら、3球の中で中枢への経路を完成させるピンボール。

`DOPPAN`という名前は開発中の呼称として仮採用する。検索結果には同名の個人利用があり、J-PlatPatとWIPOの法的なクリアランス結果も取得できていないため、正式公開名としては未確定のままG7で再確認する。

この状態でG0.5の工程上の成果物は完了とするが、名称の権利保証や正式ロゴ制作は行わない。
