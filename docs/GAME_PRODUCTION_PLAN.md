## 1. この文書の役割

本書は、DOPPANを「動くピンボール」ではなく、スマホブラウザ上で明確な技能、判断、上達、作品固有の達成感を持つゲームとして完成させるための最上位計画である。

本書が正本となる内容:

- 制作目的
- 対象プレイヤー
- 作品方針
- 正式版1.0の範囲
- 制作段階とゲート
- 制作予算と中止条件
- 公開判断
- 公開後の成果

技術、数値、試遊、中心体験、GitHub Pages運用の詳細は、各正本文書へ委ねる。

判断の優先順位:

1. 安全、権利、プレイヤーの公平性
2. プレイヤー体験
3. 作品固有の価値
4. 品質ゲート
5. 実装都合
6. 既に作った量

既に作った量は、品質不足を受け入れる理由にしない。

## 2. 制作目的

### 2.1 主目的

DOPPANを、カメレオンJPの代表作候補として公開できる、縦持ちスマホ向けブラウザゲームへ完成させる。

代表作候補の条件:

- 公開URLを開くだけで遊べる
- 初見でも基本操作を理解できる
- 操作の上達が結果へ反映される
- 一枚の盤面を繰り返し攻略する価値がある
- 15秒程度の映像で固有の面白さを示せる
- 技術実験ではなく作品として紹介できる

### 2.2 補助目的

- スマホ向け2D物理ゲームの制作・試験基盤を作る
- AI支援の一人制作でも企画、実装、試遊、公開判断を分離する
- 将来再利用できる入力、物理、盤面データ、得点分析を残す

### 2.3 主目的にしないもの

正式版1.0では次を主目的にしない。

- 直ちに収益化
- 毎週更新するライブサービス
- 多数盤面の運営
- 実機ピンボールの完全再現
- 3D表現そのもの
- ランキングだけで継続理由を作ること

## 3. 作品の暫定的な約束

現段階の仮説:

> **発射強度を決め、左右のタッチで球を受け止めて狙い直し、正確なショットをつなぐほど盤面が変化する、縦持ちスマホ向けの技能型ピンボール。**

G2で最終化する。

確定条件:

- ピンボール以外の固有価値が入る
- 実際の操作と矛盾しない
- 代表的な仕組みを説明している
- 市場比較で他作品との差を示せる
- 正式版1.0の範囲で証明できる
- 15秒の動画で伝えられる

「覚醒」「爽快」「派手」だけでは固有価値としない。

## 4. 対象プレイヤー

### 4.1 主対象

スマホで3〜8分程度の技能型ゲームを遊びたい人。ピンボール経験は問わない。

求める状態:

- インストールと会員登録なし
- 長い説明を読まずに開始
- 偶然だけでなく操作が結果へ反映
- 失敗理由を理解して改善
- 一回ごとに明確な終了
- 短時間でも上達を実感

### 4.2 副対象

ピンボール経験者、スコアアタック経験者、球の扱いと経路選択を練習したい人。

提供する価値:

- フリッパー位置とタイミングによる球筋の差
- 球を受けて狙い直す余地
- 安全、中核、危険ショット
- 成功後の戻りを含む経路設計
- 得点内訳による自己改善

### 4.3 主対象にしない層

- 実機と同じ傾斜、部品、台揺らしを求める層
- 長時間の育成、収集、物語が主目的の層
- 版権や3D映像だけを期待する層
- リアルタイム対戦を最優先する層

## 5. ゲームデザインの五つの柱

1. **触った瞬間に返る**
2. **狙いが結果へ反映される**
3. **盤面を理解すると上達する**
4. **成功が段階的に高まる**
5. **公平に終われる**

これらは品質方針であり、DOPPAN固有の仕組みではない。固有性は[中心体験・表現計画](./CORE_EXPERIENCE_PLAN.md)で決める。

## 7. 完成前のGitHub Pages方針

- GitHub Pagesをユーザー本人のiPhone確認に使用
- 完成前はURLをREADME、SNS、公開サイト、記事へ掲載・案内しない
- 本番ルートへ未完成ゲームを配置しない
- 確認ページは信頼済みブランチ一件だけ
- 検索除外を設定
- GitHub Pagesは公開URLであり、推測アクセスを完全には防げない
- 第三者へ確認URLを配布しない
- `main`への取り込みだけでは正式公開しない
- G7後の手動承認で正式公開

詳細は[公開・プレビュー・安全運用計画](./DEPLOYMENT_AND_SECURITY_PLAN.md)を正本とする。

## 9. 正式版1.0の基本ルール

GA検証仕様として決定する。

### 9.1 ゲーム単位

- 1ゲーム3球
- 中央値3〜6分を仮目標
- 90パーセンタイル10分以内を仮目標
- 最終球だけ秘密に物理難度を変えない

### 9.2 球をまたぐ進行

保持:

- 恒久進行
- 完成済み主要目標
- 基本倍率の恒久上昇
- クライマックス準備

球終了で解除:

- コンボ
- 制限時間付き倍率
- 一時案内
- 短時間モード
- 入力状態

ボールセーブ再発射では球数と進行を減らさない。

### 9.3 発射

- G1-Bで操作方式を比較
- GAで基本スキルショットを一つ検証
- 攻略価値、再現性、初見理解が不足すれば固定発射

### 9.4 中断と保存

- 画面非表示では安全停止
- 再読み込み、タブ終了、強制終了では進行中ゲームを復元しない
- 最高得点と設定をゲーム終了時に保存
- 保存の永久保持は保証しない
- 時間切り捨てなどで公正性を失ったゲームは自己最高へ保存しない

## 10. 一枚盤面の習熟

- 1ゲーム目: 入力、発射、安全ショット
- 2〜5ゲーム目: 球の受け方、中核ショット、球間進行
- 5〜10ゲーム目: 戻り、左右経路、危険ショット
- 10ゲーム以降: クライマックス、得点経路最適化
- 熟練後: 同じ到達を少ない失敗で再現

初回だけ面白く、理解後に選択がなくなる盤面は不合格。

---

## 11. 球受け・保持

絶対条件ではなく中心技能候補。

残す条件:

- 狙い直しで新しい判断が生まれる
- 初心者は知らなくても安全ショットを遊べる
- 常時の不自然な補正を必要としない
- 盤面速度を不自然に下げない
- 経験者が再現できる

分岐:

- 中心技能
- 上級技能
- 初回案内から除外
- 作品約束から除外

## 12. 正式版1.0の範囲

### 12.1 必須

- 安定した一盤面
- 安全、中核、危険、発射スキルショット
- 球を受けて狙い直す余地
- 球をまたぐ進行
- 代表的な仕組み
- クライマックス1種類
- 得点と進行の理解
- 端末内最高得点
- 音なし
- 点滅、粒子、画面揺れの軽減
- 高コントラスト
- 公開URL、操作説明、更新履歴
- WebGL非対応案内
- 不具合報告導線

球の保持は、G1-BとGAで面白さを増すと確認できた場合だけ必須に残す。

### 12.2 可能な限り含める

- 基本練習3課題以内
- 得点内訳
- 結果テキスト共有
- 事実に基づく簡単なプレイ集計

### 12.3 公開後でもよい

- 詳細な改善提案
- 共有画像
- 詳細練習
- ゴースト
- リプレイ
- ランキング
- 外部テレメトリー

公開後候補を理由にv1.0を延期しない。

| 段階 | 上限 |

| G1-A | 基盤PR 1件、終了後確認1件まで |

## 15. 試遊

試遊は[試遊実施手順](./PLAYTEST_PROTOCOL.md)を正本とする。

完成前は第三者へURLを配布しない。

原則:

- ユーザー本人が自分の端末で確認ページを開く
- 対面で端末を参加者へ渡す
- 試遊後に回収
- URLをメッセージ、QR、SNSで渡さない

見る内容:

- 初回発射
- 入力理解
- ショット試行と成功
- 球の視認性
- 落下場所
- 得点構成
- 公平感
- 終了後満足
- 次に改善したい行動
- 3〜5ゲーム後の上達

人数不足を成功扱いにしない。

## 19. 主要リスクと中止条件

| リスク | 早期兆候 | 対応 |
|---|---|---|
| 技術基盤が大きすぎる | 一PRでCIと物理を同時構築 | G1-A/Bへ分割 |
| 短いタップ消失 | 押下・解放が描画前に完了 | InputEventQueue |
| 二重ループ | PixiTickerと独自loop | 単一所有、HMR停止 |
| 球終了消失 | 非表示と落下が同時 | pendingTerminalEvents |
| 接触二重得点 | beginとpostSolve混同 | 用途別イベント |
| 物理命令不整合 | 開閉・破棄競合 | 競合表、上限超過停止 |
| Pages誤公開 | mainマージで本番更新 | G7手動公開のみ |
| URL拡散 | READMEやSNS掲載 | 完成前掲載禁止 |
| 同一オリジン保存 | 開発版が本番キー使用 | 環境キー、信頼済みコード限定 |
| 物理は正しいが面白くない | 球受け・狙いが不要 | 企画側撤退条件 |
| 盤面が部品一覧 | 戻りがない | G2停止 |
| 演出で弱さを隠す | 仮図形で面白くない | 本番素材停止 |
| 得点攻略が単調 | 一得点源集中 | 得点、戻り、進行再設計 |
| 性能不足 | 時間切り捨て反復 | 表示削減、記録無効化 |
| 試遊証拠不足 | URL非配布で人数不足 | 証拠不足として残す |
| 権利不明 | 出所記録なし | 公開禁止 |
