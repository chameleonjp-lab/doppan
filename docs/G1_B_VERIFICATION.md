# G1-B verification record

G1-Bは、本番盤面や操作感を確定する段階ではなく、入力、固定時間、Planck物理、接触整理、状態、安全停止を自動試験できる最小構成を確認する段階です。端末固有の二本指、Safari挙動、体感遅延、発熱はGA開始時へまとめて引き継ぎます。

## 技術判断

| 項目 | 判断 | 根拠 |
| --- | --- | --- |
| 物理エンジン | `planck` 1.5.0をG2まで継続 | 60Hz・120Hzの双方で実衝突行列と安全停止試験が通過 |
| 既定の物理Hz | 60Hz | 120Hzだけが解決する破綻は未検出。120Hz比較経路は保持 |
| 発射操作 | 長押しして明示的に離す方式を技術候補とする | 3帯を乱数なしで再現し、cancel・blur・非表示・ポーズでは発射しない |
| 端末確認 | GA開始時へ繰り延べ | 日常PRは型、単体、物理、Chromium、WebKitを通過条件とする |

## 独立レビューで修正した重大事項

- 最大発射が主盤面へ出られない形状を、実体のある案内板とレーン開口へ修正
- リセット後の物理step ID不一致を修正
- cancel、blur、非表示、ポーズ後の意図しない発射を禁止
- 球落下のpending terminal eventを復帰後に処理し、落下stepの得点を抑止
- WebGL喪失を入力・物理・得点停止、run integrity無効、明示リセット必須へ接続
- 10,000件行列を、外周角と固有初期条件を含み、対象への実衝突を証明する13,824件へ置換
- 非表示時間を次のRAF差分へ混入させないよう修正
- body破棄時に物理だけが消えて表示・runtime登録が残る不整合を修正
- 球終了時に入力と前の球の安全位置を残さないよう修正
- 行列の各caseで球の角速度を0へ戻し、初期条件を完全に記録
- 安全位置の円対fixture判定を5点標本からPlanck shape overlapへ変更
- gateのopen/closeを物理filter、runtime、表示snapshotで同期
