## D-045 個人アカウントと利用者識別

- 状態: 決定
- 承認日: 2026-08-10
- 承認者: ユーザー本人
- 決定:
  - 個人アカウントを作らない
  - ログインを作らない
  - プレイヤー名を保存しない
  - 永続的な利用者識別子を作らない
  - 端末指紋を使わない
- 理由:
  - DOPPANの中心体験に不要
  - アカウント復旧、認証、個人情報管理を不要にする
  - 静的な無料ゲームとしてGitHub Pagesの用途を明確にする
- 影響:
  - 認証ライブラリ、認証画面、利用者テーブルを実装しない
  - 別端末への引き継ぎを提供しない
- 見直し条件:
  - ユーザー本人が別計画として明示承認し、保存目的、削除方法、費用、規約、ホストを再検証した場合のみ

## D-046 ゲーム記録の非保存

- 状態: 決定
- 承認日: 2026-08-10
- 承認者: ユーザー本人
- 決定:
  - 得点、最高得点、得点内訳の自己最高を保存しない
  - 戦績、履歴、プレイ回数、継続日数を保存しない
  - ランキング、リプレイ、ゴーストを正式版1.0へ入れない
  - 一回のゲーム状態はブラウザのメモリ内だけで保持する
  - 再挑戦、再読み込み、タブ終了後へ引き継がない
- 理由:
  - 記録保存は中心体験の成立に不要
  - データベース、外部通信、不正対策、保存移行を不要にする
- 影響:
  - 既存文書の「端末内最高得点」「自己最高へ保存」「スコア保存キー」は失効
  - `runIntegrity`は結果の信頼性表示と診断にだけ使い、保存可否には使わない
  - 結果共有は現在のメモリ上の結果文から作る

## D-047 端末内設定だけを許可

- 状態: 決定
- 承認日: 2026-08-10
- 承認者: ユーザー本人
- 決定:
  - 音、画面効果、高コントラスト、初回案内などの非個人設定だけを端末内保存してよい
  - 設定へ氏名、得点、日時、回数、利用者ID、端末IDを含めない
  - 設定保存が使えなくても正常に起動・プレイできる
  - 開発確認版、本番版、試験版の設定キーを分ける
- キー:

```text
doppan:development-preview:settings:v1
doppan:production:settings:v1
doppan:test:settings:v1
```

- 影響:
  - `src/storage/save-storage.ts`は設定専用へ用途を狭める
  - ゲーム記録を受け取れる汎用型のまま正式版へ残さない

## D-048 正式版1.0の外部サービス

- 状態: 決定
- 承認日: 2026-08-10
- 承認者: ユーザー本人
- 決定:
  - Supabase、Cloudflare Workers、Cloudflare D1、Firebase、独自サーバーを使わない
  - 認証、外部データベース、ランキング、外部分析、広告、決済を使わない
  - DOPPANのコードからプレイ開始・終了、得点、識別情報を送信しない
- 構成:
  - GitHubリポジトリ
  - GitHub Actionsによる開発、試験、ビルド、配置
  - GitHub Pagesによる静的配信
  - プレイヤー端末内のゲーム実行

## D-049 GitHub Pagesの条件付き採用

- 状態: 決定
- 承認日: 2026-08-10
- 承認者: ユーザー本人
- 決定:
  - 正式版1.0はGitHub PagesとGitHub Actionsだけで運用する
  - 無料の静的ゲーム、非商取引、決済なし、アカウントなし、利用者データ収集なしを維持する
  - GitHub Actionsは開発、試験、ビルド、配置だけに使う
  - G7でGitHub PagesとGitHub Actionsの最新規約を再確認する
- 運用想定:
  - 1日100人
  - 1日200プレイ
  - 初回転送3MB以内
  - 総容量10MB以内
  - 厳しい条件で約60GB／月
- 内部停止線:
  - 月間転送量見積もり70GB超
  - GitHubから警告
  - HTTP 429の反復
  - 1GBへ近づく
  - 商取引、アカウント、サーバー処理が必要になる
- 見直し:
  - 条件に該当したらPages公開を止め、機能削減または別ホスト移行を新しい計画としてユーザー承認へ戻す
