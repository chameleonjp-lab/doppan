## 3. データ非保存の決定

正式版1.0は、ゴッドフィールドのような個人アカウントを作らず、個人の記録も保存しない。

保存しないもの:

- プレイヤー名、ログイン、アカウント、永続的な利用者識別子
- 得点、最高得点、得点内訳の自己最高
- 戦績、プレイ履歴、プレイ回数、継続日数
- ランキング、リプレイ、ゴースト
- 外部分析用の行動履歴

一回のゲーム状態はブラウザのメモリ内だけで保持し、再挑戦、再読み込み、タブ終了後へ引き継がない。

端末内保存を許可するのは、音、画面効果、高コントラスト、初回案内などの非個人設定だけとする。設定保存が失敗してもゲームを継続する。

既存の`src/storage/save-storage.ts`は、ゲーム記録用の汎用保存として使わない。設定実装PRまでに、設定専用の名称、型、試験へ修正する。

## 4. 完成前のGitHub Pages方針

- GitHub PagesをiPhone確認に使用
- 完成前はURLをREADME、SNS、公開サイト、記事へ掲載・案内しない
- ユーザー本人だけがGitHub Actionsなどから確認URLを開く
- 本番ルートへ未完成ゲームを置かない
- 確認ページは信頼済みブランチ一件だけ
- 検索除外を設定
- GitHub Pagesは公開URLであり、秘密性やアクセス制限は保証されない
- 第三者へ確認URLを配布しない
- `main`への取り込みだけでは正式版を公開しない
- G7後の手動承認で正式公開

試遊で第三者へURLを送らない。完成前の試遊は、原則としてユーザー所有端末を使った対面または管理下の確認で行う。

正式版1.0は、無料の静的ゲーム、商取引なし、決済なし、アカウントなし、利用者データ収集なしを維持する。GitHub Actionsは開発、試験、ビルド、配置だけに使い、実行時サーバー、定期集計、配信網として使わない。

## 5. 現在のBLOCKER

### G0.5

調査成果物は完了。10作品を比較し、DOPPANの仮の固有価値を「成功ショットで戻り道を組み替え、次の狙いを変える」と記録した。

残るのは正式名称と権利の確認である。`DOPPAN`は開発名として仮採用し、G7前にJ-PlatPat、WIPO、主要ストア、ドメイン、SNSを再確認する。

### 公開・端末確認の繰り延べ事項

1. `github-pages` Environmentの必須reviewerと、bootstrap push用`agent/g1a-technical-foundation`および手動更新・cleanup用`main`のdeployment branch ruleを確認しておらず、`DEVELOPMENT_PREVIEW_ENABLED`も未有効化
2. GitHub Pagesの未告知確認枠を実際に配置していない
3. 本番ルートと確認枠の成果物構成を実URLで確認していない
4. G1-Aマージ後の確認ページ終了処理を確認していない
5. iPhone Safariの表示、保存、二本指、体感遅延、発熱はGA開始時にまとめて確認する

これらはG1-B開始を止めない。Pagesを実際に配置する工程とGA開始時の端末確認で扱う。

### G1-B

PR #8のマージにより通過扱い。自動ゲート上のBLOCKERはない。球受けから安全ショットへつながる通常プレイ経路は未成立であり、G2の盤面設計で再判断する。

### G2

PR #10のマージにより、自動ゲート上は通過扱い。戻り再構成型、固有動詞「つなぎ直す」、ショットマップv0.1、次目標と戻りゲートの切り替えを仮図形へ実装した。G3 / GAで初見理解、反復時の上達、戻り変化の実効性を検証する。

### G3 / GA

現在はG2の仮図形を3球の一回のゲームへ接続している。球終了でコンボを解除し、得点と経路進行はゲーム内で保持する。3球目終了後に結果を表示し、新しいゲームで初期化する。試遊レポートはブラウザのメモリ内で生成し、表示または明示的なコピーだけを許可する。

自動検証は技術的な縦切りの合否を扱う。初見15秒理解、3〜5ゲーム後の上達、片側連打の支配性、iPhone Safariの操作感、面白さは未判定であり、管理端末の対面試遊へ残す。

### G7

1. 公開時点のGitHub Pages・Actions規約再確認が未実施
2. 公開サイト容量と想定通信量の最終確認が未実施
3. 決済、広告、アカウント、外部収集がないことの独立確認が未実施
