## 3. データ非保存の決定

正式版1.0は、ゴッドフィールドのような個人アカウントを作らず、個人の記録も保存しない。

保存しないもの:

- プレイヤー名、ログイン、アカウント、永続的な利用者識別子
- 得点、最高得点、得点内訳の自己最高
- 戦績、プレイ履歴、プレイ回数、継続日数
- ランキング、リプレイ、ゴースト
- 外部分析用の行動履歴

一回のゲーム状態はブラウザのメモリ内だけで保持し、再挑戦、再読み込み、タブ終了後へ引き継がない。

端末内保存を許可するのは、音、画面効果、高コントラスト、初回案内などの非個人設定だけとする。設定保存が失敗してもゲームを継続する。

既存の`src/storage/save-storage.ts`は、ゲーム記録用の汎用保存として使わない。設定実装PRまでに、設定専用の名称、型、試験へ修正する。

## 4. 完成前のGitHub Pages方針

- GitHub PagesをiPhone確認に使用
- 完成前はURLをREADME、SNS、公開サイト、記事へ掲載・案内しない
- ユーザー本人だけがGitHub Actionsなどから確認URLを開く
- 本番ルートへ未完成ゲームを置かない
- 確認ページは信頼済みブランチ一件だけ
- 検索除外を設定
- GitHub Pagesは公開URLであり、秘密性やアクセス制限は保証されない
- 第三者へ確認URLを配布しない
- `main`への取り込みだけでは正式版を公開しない
- G7後の手動承認で正式公開

試遊で第三者へURLを送らない。完成前の試遊は、原則としてユーザー所有端末を使った対面または管理下の確認で行う。

正式版1.0は、無料の静的ゲーム、商取引なし、決済なし、アカウントなし、利用者データ収集なしを維持する。GitHub Actionsは開発、試験、ビルド、配置だけに使い、実行時サーバー、定期集計、配信網として使わない。
